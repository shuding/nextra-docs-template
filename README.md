# 墨计科技 - 数字化解决方案领航者

一个现代、专业的企业官网，参照墨计官网设计风格，采用蓝色主色调和响应式设计。

## 🌟 特性

- ✨ **现代设计**：参照 Emodor 官网设计风格，简洁专业
- 🎨 **蓝色主题**：企业级蓝色配色方案，体现专业与信赖
- 📱 **响应式设计**：完美适配桌面、平板和移动设备
- ⚡ **性能优化**：基于 Next.js，快速加载与SEO友好
- 🎯 **用户体验**：流畅的动画效果和交互体验

## 🚀 功能模块

### 🏠 顶部导航栏

## 🛠️ 技术栈

- **前端框架**：Next.js 13+
- **开发语言**：TypeScript
- **样式方案**：CSS Modules
- **构建工具**：Next.js 内置
- **部署平台**：支持 Vercel、Netlify 等

## 📦 快速开始

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```

### 生产构建
```bash
npm run build
```

### 启动生产服务
```bash
npm start
```

## 🎨 设计规范

### 色彩方案
- **主色调**：#1e40af (企业蓝)
- **辅助色**：#3b82f6 (天空蓝)
- **背景色**：#dbeafe (淡蓝)
- **文字色**：#1f2937 (深灰)

### 响应式断点
- **桌面端**：> 1024px
- **平板端**：768px - 1024px
- **移动端**：< 768px
